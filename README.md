# Manvinder Arora - Product Work

A focused product portfolio for three working systems:

- Punky Trading Agent
- Telegram Brain
- Writing Desk

The site is intentionally separate from the career portfolio. It explains the
problem behind each product, the product decision, the working system loop and
the current artifact.

Public site: https://punkypunk936-coder.github.io/manvinder-product-portfolio/

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
npm run lint
npm run build:pages
```
